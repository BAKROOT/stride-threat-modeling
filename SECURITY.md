# Security Policy

This repository contains documentation, templates and small helper scripts. It does not run as a service.

## Reporting a problem

If you find a security issue in the scripts under `tools/` or `examples/`, or a mistake in the guide that could lead readers to an insecure design, please open a [GitHub security advisory](../../security/advisories/new) (private) rather than a public issue for anything sensitive. For ordinary corrections, a regular issue or pull request is fine.

## What not to submit

Do not include real system architectures, credentials, customer data, or details of unpatched vulnerabilities in issues, pull requests or examples. All worked examples must be fictional.
